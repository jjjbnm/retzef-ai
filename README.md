# Retzef AI

Retzef AI is a Hebrew, right-to-left starter workspace for creating and managing AI models.

## Current version

This repository currently contains a responsive frontend prototype with navigation for overview, models, datasets, training, playground, and settings.

## Important limitations

- Model creation is currently a local interface demo; data is not persisted.
- The playground is not connected to an AI model or inference API.
- Dataset uploads, model training, and publishing are not implemented yet.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.
